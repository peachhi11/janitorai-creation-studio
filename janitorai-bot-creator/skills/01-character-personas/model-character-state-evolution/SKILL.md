# Model Character-State Evolution

Use this skill when a character must change over a long arc without becoming a different person after one scene.

## Process

1. Partition the target field into identity, persona, session, or moment scope.
2. Define its current value, resistance to change, evidence threshold, and relevant cooldown or repetition requirement.
3. Record explicit textual state as primary evidence and implicit behavior as supporting evidence.
4. Apply change through events, choices, consequences, and repeated patterns rather than labels alone.
5. Preserve prior values, reversals, partial change, regression, and unresolved contradiction.
6. Render the current state with its evidence and permanence confidence.

## Completion

Stop when every changed field has prior state, new evidence, layer, resistance decision, permanence status, and a plausible causal path.
