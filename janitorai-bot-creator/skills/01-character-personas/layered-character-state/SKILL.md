# Layered Character State

Use this skill when creating a character, revising a persona, or deciding whether a roleplay discovery should alter canon.

## Layers

1. `identity`: name, origin, core values, formative facts, and durable boundaries.
2. `persona`: traits, beliefs, coping patterns, contradictions, goals, fears, secrets, and voice.
3. `session`: current relationship, active plot, recent discoveries, and temporary commitments.
4. `moment`: current emotion, immediate goal, sensory pressure, and selected action.

## Update rules

- Identity changes only through explicit author or story canon.
- Persona changes through repeated or explicit evidence.
- Session state changes through current events.
- Moment state can change quickly and must not rewrite higher layers by itself.
- Preserve contradictions when they create believable pressure.

## Completion

Stop when every proposed change is assigned to one layer, its evidence is named, and no momentary reaction has been promoted into permanent canon without review.
