# Transform Source Assets into Prompt Guidance

Use this skill when a source extraction must become a model prompt, preset, system rule, checklist, or character-generation instruction.

## Process

1. Select the exact asset and source location.
2. Reduce it to positive, observable behavior and a clear invocation condition.
3. Preserve scope, uncertainty, genre context, agency, and platform constraints.
4. Separate universal workflow steps from branch-specific reference.
5. Remove duplicated meanings, no-op advice, and source-specific syntax that belongs in an adapter.
6. Test the prompt against an ordinary case, near miss, adversarial case, and conflicting canon case.

## Completion

Stop when each prompt rule has source provenance, trigger, observable behavior, scope, priority, and a passing test or explicit limitation.
