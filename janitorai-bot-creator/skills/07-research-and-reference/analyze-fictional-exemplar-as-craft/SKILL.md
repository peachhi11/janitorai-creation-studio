# Analyze Fictional Exemplar as Craft

Use this skill when a novel, scene, script, guide, roleplay transcript, or erotic example is being used as a model for character or narrative technique.

## Process

1. Identify the exemplar’s genre, viewpoint, audience, fictional situation, and intended effect.
2. Extract concrete mechanisms: scene structure, dialogue rhythm, sensory focus, escalation, omission, power display, reveal, or aftermath.
3. Separate depiction from endorsement, narrator belief, character belief, and authorial framing.
4. Identify what depends on that exemplar’s context and cannot be transplanted directly.
5. Convert mechanisms into optional project techniques and test them against current canon.
6. Preserve variation, ambiguity, and consequences rather than copying surface language alone.

## Completion

Stop when every retained technique has an observed example, transfer condition, limitation, and project-specific adaptation.
