## Steps

1. State the creative decision, blockage, audience, output, and time available.
2. List existing worksheets, prompts, templates, constraints, and repeated questions.
3. Keep only questions whose answers will change a scene, character, setting, revision, or process decision.
4. Group prompts by decision and remove duplicates, abstractions, and decorative sections.
5. Order prompts from known context to choice, consequence, uncertainty, and next action.
6. Add examples using {{char}} and {{user}} where roleplay is involved.
7. Test the worksheet on one real creative problem and remove prompts that produce no usable change.
8. Keep optional prompts optional and leave unknowns open.

## Decision rules

- Yes: Does a prompt change no creative decision? Remove it. No: keep it.
- Yes: Does the worksheet assume one genre, relationship, culture, or healthy outcome? Make the assumption explicit or remove it. No: continue.
- Yes: Is a question asking {{user}} to surrender player-owned choice? Reword it as an open option. No: continue.
- Yes: Is the worksheet too long for the stated task? Keep the smallest useful set. No: continue.

## Output

- Format: `Adapted writing worksheet`
- Goal: state the creative problem and success condition.
- Prompts: list the ordered questions with optional markers.
- Example: provide one short {{char}}/{{user}} example where relevant.
- Test: show the answer that changes a real decision.
- Deferred: list prompts removed or left for later.

## Stop when

- No creative problem, worksheet, or prompt set is supplied: return `No worksheet update` and do not invent a task.
