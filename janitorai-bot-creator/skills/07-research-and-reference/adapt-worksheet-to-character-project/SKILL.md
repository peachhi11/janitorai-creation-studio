# Adapt Worksheet to Character Project

Use this skill when a source provides prompts, exercises, templates, trackers, questionnaires, or planning frameworks.

## Process

1. Identify the worksheet’s purpose, assumptions, required inputs, implied audience, and intended output.
2. Keep useful questions, structures, pacing tools, and tracking fields.
3. Remove redundant, culturally narrow, diagnostic, prescriptive, or genre-incompatible assumptions.
4. Add project-specific identity, relationship, world, knowledge, agency, and genre fields.
5. Mark optional, required, unknown, and author-decision fields.
6. Test the adapted worksheet on a sample character without forcing answers or an ending.

## Completion

Stop when the worksheet has a clear project purpose, usable fields, preserved agency, explicit optionality, and no imported rule that conflicts with canon or genre intent.
