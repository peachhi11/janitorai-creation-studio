# Extract Structured Document Corpus

Use this skill when processing a source page by page or converting a mixed document batch into reusable Studio assets.

## Process

1. Read the document in order and identify headings, tables, figures, appendices, code cells, and metadata.
2. Separate instructions addressed to the original reader from information useful to the Studio.
3. Extract only concrete assets: technique, rule, schema, tracker, prompt, tool, guideline, guardrail, style, template, structure, engine, or evaluation method.
4. Record exact page or section location and quote only as much as needed to preserve meaning.
5. Classify each asset as evidence, craft guidance, implementation pattern, fictional exemplar, hypothesis, or unverified claim.
6. Deduplicate equivalent assets while preserving distinct source provenance.
7. Route assets into the appropriate skill, reference ledger, implementation note, or archive.

## Completion

Stop when every readable section has been dispositioned, every retained asset has a source location and use limitation, and the document’s unreadable or unprocessed portions are explicit.
