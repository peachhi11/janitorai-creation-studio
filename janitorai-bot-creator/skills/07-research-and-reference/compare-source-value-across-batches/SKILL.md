# Compare Source Value Across Batches

Use this skill when a new upload batch arrives or when the repository needs a value assessment rather than another title inventory.

## Process

1. Normalize titles, authors, dates, formats, hashes, and source relationships.
2. Compare claims, mechanisms, schemas, templates, tools, and guardrails with the existing corpus.
3. Identify novel value, stronger evidence, alternate framing, worked example, implementation detail, redundancy, and conflict.
4. Assign disposition: core, support, context, flagged, archive, duplicate, or unresolved.
5. Link retained value to skills, ledgers, prompts, tests, or reference storage.
6. Record what the batch does not establish.

## Completion

Stop when every batch item has a comparative disposition, every retained novelty has a destination, and unsupported or duplicated material is explicitly marked.
