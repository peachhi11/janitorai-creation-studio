# Repository Skills

This directory contains compact, actionable modules distilled from Library references.

Skills are implementation guidance, not universal psychological laws and not automatic canon. Each skill names its source Library files and should be reviewed when the source is revised. Platform-specific behaviour belongs in adapters; project-specific facts belong in project canon.

## Current modules

- `relationship-conflict-tracker`: tracks relationship dimensions and conflict causes across scene updates.
- `world-continuity`: maintains a living contemporary setting without making every project modern-day.
- `character-construction`: links character dimensions, motives, capabilities, and story function.
- `emotional-logic`: turns static rules and vague traits into observable behavioural causes.
- `romance-route-design`: selects and applies romantic tropes without forcing a route or ending.

The source ledger in `knowledge/source-ledger.json` records provenance and disposition for these modules.
