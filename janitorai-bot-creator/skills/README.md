# Repository Skills

This directory contains compact, actionable modules distilled from Library references.

Skills are implementation guidance, not universal psychological laws and not automatic canon. Each skill names its source Library files and should be reviewed when the source is revised. Platform-specific behaviour belongs in adapters; project-specific facts belong in project canon.

## Purpose-led skill library

The expanded local library is organised by the task a writer is trying to
perform. The folders below are the canonical homes for the imported modules;
each skill remains independently triggerable and can be adapted by the platform
layer without changing project canon.

- `01-character-personas` — personality, identity, psychology, history, and behaviour.
- `02-relationships-intimacy` — relationships, attraction, erotic dynamics, power, conflict, intimacy, and aftermath.
- `03-cast-and-npcs` — ensembles, families, recurring NPCs, factions, institutions, and witness networks.
- `04-worldbuilding-and-setting` — cultures, beliefs, ecologies, institutions, geography, naming, and setting consequences.
- `05-narrative-writing` — viewpoint, dialogue, scenes, pacing, prose, escalation, and interactive narrative.
- `06-continuity-and-knowledge` — canon, memory, state deltas, reveals, belief, inference, and disclosure boundaries.
- `07-research-and-reference` — provenance, evidence tiers, OCR, deduplication, cultural research, and source preparation.
- `08-testing-and-quality` — craft, agency, framing, coherence, multimodal evaluation, coverage, and regression audits.
- `09-platform-and-exports` — prompt stacks, context budgets, character cards, compatibility, workflows, and exports.

The expanded library applies Fictional Genre Logic and Narrative Intention as
cross-cutting standards. These preserve genre-specific causality, character
agency, player sovereignty, and intentional darkness without treating fictional
patterns as universal psychology or real-world operating instructions.

See `TAXONOMY.md` for the folder map and counts. The original compact modules
above remain available for backwards compatibility.
