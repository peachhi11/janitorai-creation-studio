# Run Adversarial Roleplay Regression

Use this skill when a prompt, skill, model, retrieval path, or character card changes and hidden failure modes need to be exposed.

## Process

1. Build adversarial cases for embedded document instructions, conflicting source claims, stale memory, multi-character collapse, sycophancy, impossible knowledge, and player authorship.
2. Add genre cases for darkness, erotic tension, coercive depiction, ambiguity, tragedy, refusal, and non-resolution.
3. Run normal and adversarial cases through the same workflow.
4. Compare state, voice, grounding, agency, framing, and error behavior.
5. Classify failures as prompt, retrieval, state, tool, schema, policy, or intentional-fiction disposition.
6. Preserve minimal failing fixtures and repair only the responsible layer.

## Completion

Stop when every adversarial branch has an expected disposition, observed result, failure classification, and regression fixture or explicit accepted limitation.
