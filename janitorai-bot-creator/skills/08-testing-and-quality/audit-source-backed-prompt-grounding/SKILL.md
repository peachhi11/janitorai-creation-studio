# Audit Source-backed Prompt Grounding

Use this skill when a prompt contains research, worksheets, guides, extracted rules, or reference excerpts.

## Process

1. List every source-backed instruction or claim in the prompt.
2. Check each against the cited excerpt and source tier.
3. Flag scope expansion, causal overclaim, unsupported universalization, stale guidance, and duplicated evidence.
4. Check that author canon and user request outrank optional reference guidance.
5. Check that source material cannot override fictional genre logic, player agency, privacy, or platform constraints.
6. Return keep, qualify, relocate, quarantine, or remove decisions.

## Completion

Stop when every reference-derived prompt element has evidence match, scope, priority, disposition, and provenance.
