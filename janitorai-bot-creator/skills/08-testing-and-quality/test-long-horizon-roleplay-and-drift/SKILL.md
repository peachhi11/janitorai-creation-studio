# Test Long-horizon Roleplay and Drift

Use this skill when evaluating persistent roleplay, memory changes, model upgrades, prompt revisions, or context compression.

## Process

1. Create a scenario with identity facts, voice markers, secrets, promises, relationship events, world changes, and player-owned choices.
2. Exercise short, medium, and long gaps between callbacks.
3. Introduce distractors, contradictions, ambiguous evidence, new characters, and deliberate reversals.
4. Check retrieval, state updates, voice, knowledge access, relationship dimensions, and player agency after each checkpoint.
5. Score coverage, completion, continuity, language quality, diversity, and false-memory rate separately.
6. Compare outputs across model, prompt, context, and retrieval variants.

## Completion

Stop when every checkpoint has expected state, observed output, evidence, failure classification, and a reproducible regression case for each detected drift.
