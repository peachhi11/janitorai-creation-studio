# Audit Skill Invocation and Pointers

Use this skill when adding a skill, reorganizing the taxonomy, or diagnosing why an agent fails to reach the right reference.

## Process

1. Identify the exact task branches the skill handles.
2. Check that the description names those branches using concrete leading words.
3. Remove synonyms that repeat one trigger and add missing distinct branches.
4. Ensure the pointer states both what the target contains and when to reach it.
5. Keep universal steps in the skill and branch-specific reference behind disclosed pointers.
6. Test positive invocation, near-miss non-invocation, and overlapping-skill routing.

## Completion

Stop when each skill has a clear trigger, non-trigger boundary, reachable reference path, and no competing pointer that would make selection ambiguous.
