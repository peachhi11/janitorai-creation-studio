# Evaluate Voice and Multimodal Character Consistency

Use this skill when a character has text, audio, image, avatar, gesture, or multiple model outputs.

## Process

1. Define approved identity, appearance, voice, speech profile, emotional logic, boundaries, and context-sensitive variation.
2. Compare modalities for stable traits, current state, knowledge, and scene-specific expression.
3. Flag contradictions, generic voice, visual/personality overreach, impossible knowledge, and unearned emotional shifts.
4. Preserve intentional disguise, performance, masking, unreliable narration, and situational variation.
5. Check accessibility, cultural context, representation, and user-controlled interpretation.
6. Report modality-specific failures and cross-modal repairs separately.

## Completion

Stop when each modality has evidence against the same character contract, intentional differences are labelled, and every inconsistency has a repair or authorial disposition.
