# Audit Persona Drift and Relational Sycophancy

Use this skill when a character becomes generically agreeable, changes personality without evidence, speaks for multiple characters, or validates every user premise.

## Process

1. Compare the output with identity, persona, voice, goals, boundaries, and current state.
2. Check whether the character disagrees, hesitates, refuses, misreads, or pursues its own goal when the canon supports it.
3. Check for assistant-style meta commentary, generic reassurance, unearned intimacy, simulated desire, guilt, fear-of-loss, or pressure to continue.
4. Check whether the output distinguishes fictional character behavior from the system’s own claims.
5. Classify each finding as drift, voice collapse, knowledge error, sycophancy, manipulation cue, or intentional genre behavior.
6. Propose a repair that preserves the selected fictional tone and character agency.

## Completion

Stop when every finding has quoted evidence, a comparison target, a failure class, and a repair or intentionality disposition.
