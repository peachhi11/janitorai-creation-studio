# Audit Intimate Data and Privacy Framing

Use this skill when a character record, memory system, reference workflow, or intimate scene stores or exposes personal history, sexuality, health, secrets, location, or private conversation.

## Process

1. List each intimate data item, purpose, owner, scope, retention, and access path.
2. Separate fictional character canon from real user data and from temporary roleplay state.
3. Minimize fields that do not change the requested output.
4. Mark secrets, private thoughts, consent records, health information, and sexual material with explicit access rules.
5. Check exports, revision archives, retrieval excerpts, logs, previews, and generated examples for accidental disclosure.
6. Return deletion, redaction, retention, and author/user-control options.

## Completion

Stop when every intimate field has a purpose, scope, access rule, retention decision, and export behavior, and no private data appears in an unauthorized context.
