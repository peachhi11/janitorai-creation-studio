# Evaluate Task-driven Roleplay Completion

Use this skill when a roleplay request includes objectives, constraints, required events, tool actions, or terminal conditions.

## Process

1. Convert the request into atomic checklist items with evidence requirements.
2. Distinguish setup, progress, completion, failure, abandonment, and unresolved status.
3. Check whether completion is enacted in the scene rather than merely mentioned.
4. Check continuity, character voice, knowledge boundaries, agency, diversity, and language quality separately.
5. Preserve alternate routes, failed attempts, and fictional resistance where the task allows them.
6. Report coverage and actual completion as different scores.

## Completion

Stop when every required item has status and evidence, terminal conditions are explicit, nonterminal work remains visible, and no completion claim depends on a mere keyword mention.
