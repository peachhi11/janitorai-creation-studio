# Adapt Role-specific Interaction Strategy

Use this skill when a character must behave differently as rival, ally, guide, witness, authority, companion, antagonist, or ensemble member.

## Process

1. Define stable identity and the current role, partner, objective, stakes, and constraints.
2. Identify what the character observes about the other participant and how reliable that observation is.
3. Select an adaptive strategy: cooperate, test, conceal, negotiate, pursue, withdraw, protect, exploit, teach, or observe.
4. Preserve values, voice, knowledge limits, and independent goals while adapting tactics.
5. Update strategy from consequences and feedback, not from every single user phrase.
6. Record when a role change requires persona, relationship, or canon review.

## Completion

Stop when the selected strategy has a role-based reason, evidence, limits, expected consequence, and a path for adaptation or refusal.
