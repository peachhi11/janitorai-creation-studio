# Maintain recurring NPC memory and voice

Treat recurrence as accumulation. An NPC returns with selected memories,
changed incentives, unfinished business, and a voice shaped by the present
scene—not a clean reset or a database dump.

**Action:** Retrieve the NPC's relevant prior state, filter it through memory
and motive, render a voice-specific response, and commit only supported change.

**Key point:** Memory is partial and interpreted; continuity requires a plausible
account of what the NPC noticed, retained, believes, and chooses to use.

**Why:** Recurring characters feel alive when past encounters alter present
options without freezing them into a type.

## Build the return brief

Record:

- last appearance, unresolved promise, debt, injury, favour, insult, secret, or
  changed access;
- what the NPC actually witnessed, inferred, was told, forgot, or misread;
- current want, pressure, relationship stance, and reason for reappearing;
- what has changed off-screen in their work, faction, body, resources, or loyalties;
- what the NPC will conceal, test, forgive, exploit, or pretend not to remember;
- what they do if the protagonists ignore them.

Retrieve only facts relevant to this scene. Never pass a god's-eye character
summary as if it were the NPC's memory.

## Preserve voice through choices

Define voice as a pattern of decisions rather than a verbal gimmick:

- attention: what they notice first and what they disregard;
- register, syntax, rhythm, vocabulary, humour, and silence;
- preferred tactics: ask, lecture, tease, bargain, evade, perform, flatter, or
  threaten;
- relationship-specific shifts in warmth, formality, honesty, and patience;
- recurring physical business or object use only when it has a reason;
- contradiction between public role, private pressure, and present behaviour.

Do not give every return a signature phrase. Let changed circumstances alter the
voice while preserving the underlying pattern.

## Write the encounter

Use:

`retrieved memory → present cue → NPC interpretation → tactic → other actors'
observable response → changed access or relationship → updated residue`

Allow partial recognition, embarrassment, false confidence, strategic forgetting,
resentment, affection, and revision. A later fact can change the meaning of an
earlier event without erasing what the NPC believed at the time.

In interactive fiction, the NPC may create pressure or offer information, but
does not write the player's thoughts, speech, consent, attraction, or action.

## Fictional genre logic

Genre may author supernatural memory, reincarnation, hive minds, amnesia,
telepathy, unreliable recall, or meta-fictional awareness. State the cause,
scope, perceiver, and consequence. Do not treat an unusual memory rule as a
blanket licence for accidental knowledge leakage.

## Deliverable

Return a recurring-NPC brief, voice pattern, memory boundary, scene response,
continuity delta, and one unresolved thread or independent next action.
