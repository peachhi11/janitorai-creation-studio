# Assemble Research-backed Generation Prompt

Use this skill when generating or revising a character, persona, scene, relationship route, or world element with retrieved references.

## Process

1. Establish authority order: platform contract, user request, approved canon, current state, selected genre, source guidance, optional examples.
2. Retrieve only sources relevant to the requested branch.
3. Label evidence, interpretation, proposed change, and invention separately.
4. Add character, relationship, world, knowledge, agency, and output-schema constraints needed for the task.
5. Budget context and reserve output space before adding optional material.
6. Inspect the assembled prompt for contradictions, stale state, unsupported certainty, and unauthorized player authorship.

## Completion

Stop when the prompt contains all required authority and current state, excludes irrelevant or stale material, preserves provenance, and passes a pre-generation contradiction and agency check.
