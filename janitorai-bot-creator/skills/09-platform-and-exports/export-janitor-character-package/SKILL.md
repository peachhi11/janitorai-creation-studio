# Export JanitorAI Character Package

Use this skill when a character is ready for platform export or when a revision must be checked before replacing an existing package.

## Process

1. Load only approved canon and explicitly selected genre or prompt presets.
2. Validate required fields, identity consistency, voice, scenario, greeting, example dialogue, boundaries, and knowledge limits.
3. Separate platform syntax from portable character content.
4. Preserve source provenance and proposed-versus-confirmed changes in the revision record, not in the character’s in-world voice.
5. Render the character package, compact summary, scenario memo, and optional portable persona export.
6. Run interoperability and continuity checks before writing or replacing the record.

## Completion

Stop when the package validates against its target schema, all required fields are present, player agency is preserved, unresolved author decisions are surfaced, and the export can be restored or traced to its source revision.
