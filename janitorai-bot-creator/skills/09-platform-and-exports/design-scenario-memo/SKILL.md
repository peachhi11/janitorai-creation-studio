# Design Scenario Memo

Use this skill when converting a long concept, prior session, or source-backed character package into a compact runtime scenario.

## Process

1. Record the current time, place, participants, relationship status, and immediate situation.
2. Record only active plot points, accessible knowledge, promises, secrets, injuries, objects, and unresolved pressure.
3. Separate stable character canon from session-specific state.
4. Preserve uncertainty, competing interpretations, and player-owned choices.
5. Order the memo by what can change the next response.
6. Check that compression did not delete a boundary, knowledge restriction, or active consequence.

## Completion

Stop when the memo is shorter than the source material, contains every next-turn-critical fact, labels uncertainty and scope, and can be used without replaying the entire history.
