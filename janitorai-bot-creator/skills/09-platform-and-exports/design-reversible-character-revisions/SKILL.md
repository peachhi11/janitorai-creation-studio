# Design Reversible Character Revisions

Use this skill when revising an existing character, applying a source-backed change, or preparing a character for persistence.

## Process

1. Snapshot the current approved record.
2. Record requested changes, source references, prompt preset, and author decisions.
3. Produce a proposed revision with a field-level change summary.
4. Validate identity, voice, relationship, knowledge, genre, and export contracts.
5. Save only after approval; archive the displaced record before replacement.
6. Make restore and comparison paths explicit in the handoff.

## Completion

Stop when the current record, proposed changes, archived predecessor, provenance, validation result, and restore identifier are all available.
