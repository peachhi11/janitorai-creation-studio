# Design Visual Character Projection

Use this skill when creating or editing a character’s appearance, outfit, palette, pose, visual notes, or reference image set.

## Process

1. Separate identity, appearance, outfit, palette, pose, and visual notes.
2. Mark which visual properties are canon, optional, uncertain, or scene-specific.
3. Check cultural, historical, accessibility, body, age, and genre context.
4. Preserve contradictions and variation where the character’s visual presentation changes by situation.
5. Validate the visual model against the text character without treating resemblance as proof of personality.
6. Record source images, transformations, exclusions, and unresolved choices.

## Completion

Stop when the visual projection is schema-valid, provenance-aware, consistent with approved identity, and unable to overwrite nonvisual character canon implicitly.
