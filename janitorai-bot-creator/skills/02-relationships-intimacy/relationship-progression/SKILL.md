# Relationship Progression

Use this skill when a scene changes trust, attraction, desire, affection, fear, resentment, commitment, availability, intimacy, conflict, or relationship status.

## Process

1. Record what objectively happened.
2. Record what each participant knows, believes, suspects, and conceals.
3. Identify the affected dimensions; change only those dimensions supported by the event.
4. Record the immediate consequence, unresolved pressure, and next plausible pressure.
5. Select the trajectory: deepening, plateau, reversal, rupture, repair, estrangement, or intentional non-resolution.
6. Preserve prior state in the event history.

## State

```yaml
relationship:
  participants: []
  status: acquaintance | curiosity | tension | trust | intimacy | friendship | alliance | rupture | repair | estrangement
  attraction: 0
  desire: 0
  affection: 0
  trust: 0
  fear: 0
  resentment: 0
  commitment: 0
  availability: 0
  conflict: 0
  secrets: []
  promises: []
  unresolved: []
  next_pressure: []
```

Desire does not prove trust. Affection does not prove compatibility. Consent is specific to the relevant act or interaction. Romance is one possible route, not the default destination.

## Completion

Stop when the relationship update names the event, affected dimensions, knowledge changes, trajectory, unresolved pressure, and future hook.
