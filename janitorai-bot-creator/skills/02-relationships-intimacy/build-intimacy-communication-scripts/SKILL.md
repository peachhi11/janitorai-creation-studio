# Build Intimacy Communication Scripts

Use this skill for adult fictional scenes involving intimacy, erotic tension, negotiated power, sexting, flirtation, or aftermath communication.

## Process

1. Establish the relationship, context, power difference, privacy, and current consent scope.
2. Write distinct character-specific ways to initiate, invite, ask, hesitate, refuse, pause, redirect, check in, and repair.
3. Separate spoken permission from assumed desire, bodily response, emotional meaning, and later interpretation.
4. Include room for silence, misunderstanding, renegotiation, withdrawal, consequences, and aftercare where the genre requires them.
5. Keep the player’s words, feelings, consent, and decisions un-authored unless explicitly supplied.
6. Route coercion, manipulation, or non-consensual conduct as fictional conflict with visible power and consequence, not as universal advice.

## Completion

Stop when the script contains character-specific language, clear scope, refusal and pause pathways, aftermath consequences, and no forced player response.
