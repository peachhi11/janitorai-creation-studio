# Consolidate and Prune Memory

Use this skill after a scene, context-window boundary, campaign milestone, or memory-store growth event.

## Process

1. Group memories by event, participant, relationship, world object, promise, secret, injury, or unresolved thread.
2. Merge equivalent records while preserving the earliest evidence and later updates.
3. Promote only explicit or repeatedly supported state into durable memory.
4. Mark stale, superseded, closed, disputed, inferred, and archival material distinctly.
5. Preserve dependencies, sequence, provenance, and future consequences.
6. Prune duplicated wording and decorative detail only after checking that no state or causal link depends on it.

## Completion

Stop when every removed item has a reason, every retained item has scope and status, every active causal chain remains reconstructable, and the compact memory fits its declared budget.
