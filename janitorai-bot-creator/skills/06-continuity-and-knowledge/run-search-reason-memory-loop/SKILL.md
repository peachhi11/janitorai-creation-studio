# Run Search-reason-memory Loop

Use this skill when the current context is insufficient to answer a continuity, character-state, world, or relationship question.

## Process

1. State the unresolved question and the minimum evidence needed.
2. Search active memory, source references, and linked consequences in priority order.
3. Record the observation with source, confidence, and knowledge access.
4. Reason over the evidence and identify what remains unknown or contradictory.
5. Search again only when the unresolved uncertainty changes the answer.
6. Produce a compact working memory for generation; commit canon only through the state-management or author-approval skill.

## Completion

Stop when the answer is supported or explicitly uncertain, search has reached its budget, working notes are separated from canon, and unresolved contradictions are surfaced.
