# Verify State Updates

Use this skill after extracting memory, relationship, character, or world state from a scene.

## Process

1. Compare each proposed update with the exact scene evidence.
2. Separate objective event, participant interpretation, narrator claim, inference, and author proposal.
3. Check scope: identity, persona, campaign, session, or moment.
4. Check whether the update supersedes, depends on, or conflicts with active state.
5. Reject unsupported emotional conclusions and preserve unresolved alternatives.
6. Return accepted, rejected, and review-required updates with evidence.

## Completion

Stop when every proposed update has evidence, scope, source type, status, and conflict disposition, and no inferred item has silently become canon.
