# Author Approve Canon Changes

Use this skill when roleplay, retrieval, inference, or a generated revision suggests a durable change to identity, persona, relationship history, world truth, or user persona.

## Process

1. Show the proposed change in plain language.
2. Show the evidence, affected scope, dependencies, and conflicts.
3. Distinguish confirmed fact, candidate canon, interpretation, and invention.
4. Explain downstream effects on voice, relationships, plot hooks, knowledge, and exports.
5. Record approve, reject, defer, or revise without changing the underlying record prematurely.
6. Commit only the approved result and preserve the decision history.

## Completion

Stop when every proposal has an explicit disposition, evidence and scope remain attached, and no unapproved proposal is active in the generation context as canon.
