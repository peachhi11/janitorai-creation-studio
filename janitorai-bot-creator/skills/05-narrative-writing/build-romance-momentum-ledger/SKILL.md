# Build Romance Momentum Ledger

Use this skill when a slow-burn, episodic romance, friendship, or long-arc bond feels stalled, rushed, or disconnected.

## Process

1. Record the current relationship state and each participant’s active want, fear, and obstacle.
2. Track recent beats: approach, retreat, reveal, misunderstanding, repair, promise, breach, or changed access.
3. Record what intensified, delayed, redirected, or contradicted the bond.
4. Identify the next pressure that could produce meaningful change without forcing it.
5. Balance external plot momentum with emotional, informational, physical, and relational timing.
6. Preserve plateaus, reversals, independent goals, and non-romantic development.

## Completion

Stop when the ledger explains the current trajectory, names the last meaningful change, identifies active pressure, and offers multiple plausible next developments.
