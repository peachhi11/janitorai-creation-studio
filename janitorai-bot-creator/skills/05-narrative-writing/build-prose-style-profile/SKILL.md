# Build Prose Style Profile

Use this skill when a project needs a consistent prose voice across generated scenes, revisions, model changes, or collaborators.

## Process

1. Define viewpoint, tense, distance, diction, sentence rhythm, paragraph movement, and dialogue proportion.
2. Define interiority, sensory emphasis, metaphor range, humor, atmosphere, and emotional explicitness.
3. Record how style changes across tension, intimacy, action, reflection, comedy, dread, and aftermath.
4. Provide positive examples and anti-patterns tied to the selected project rather than generic “beautiful prose.”
5. Check that style serves character, genre, pacing, and player agency.
6. Test the profile on ordinary, conflict, quiet, intimate, and high-pressure scenes.

## Completion

Stop when the profile contains observable controls, situational variation, positive examples, anti-patterns, and a successful multi-scene consistency check.
