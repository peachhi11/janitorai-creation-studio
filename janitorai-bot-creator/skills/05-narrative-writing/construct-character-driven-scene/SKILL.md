# Construct Character-driven Scene

Use this skill when a character dossier needs to become an interactive scene rather than exposition or a generic situation.

## Process

1. Load the participating characters’ current motives, conflicts, knowledge, resources, and relationship state.
2. Define entry pressure, immediate wants, obstacles, and what each participant can plausibly notice.
3. Create beats where choices change access, information, power, distance, trust, risk, or desire.
4. Preserve independent goals, misunderstanding, refusal, hesitation, and player-owned response.
5. End with changed state and unresolved opportunity rather than a forced resolution.
6. Commit only evidenced state changes after the scene.

## Completion

Stop when every major beat has a character-driven cause, observable consequence, knowledge boundary, and open next action.
