# Design Interactive Scene Opportunities

Use this skill when opening a roleplay scene, recovering from a stalled exchange, or creating pressure for the next turn.

## Process

1. Establish the current location, time, participants, active pressure, and unresolved hooks.
2. Identify what changes if nobody acts, if a character acts, or if the player intervenes.
3. Create two to four plausible opportunities with different costs, information, risks, and relationship effects.
4. Keep each opportunity compatible with established knowledge and world state.
5. End on an actionable pressure point, not a demanded player reaction.
6. Record which opportunities were offered without treating any as chosen.

## Completion

Stop when the scene contains a clear present pressure, at least two materially different possible responses, visible consequences, and no authored player dialogue, emotion, consent, or decision.
