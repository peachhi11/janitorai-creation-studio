# Learn Social Conventions Through Self-play

Use this skill when developing a fictional culture, community, institution, or agent behavior model from simulated interactions.

## Process

1. Define the fictional population, setting, roles, interaction goal, and convention hypothesis.
2. Generate varied interactions with different status, knowledge, motivations, and mistakes.
3. Label observed norms, sanctions, exceptions, misunderstandings, repairs, and unresolved disagreement.
4. Separate generated convention from author canon, historical research, and real-world claim.
5. Test whether the convention changes by relationship, location, power, audience, or stakes.
6. Promote only author-approved patterns into setting rules or character knowledge.

## Completion

Stop when every proposed convention has simulated evidence, variation, scope, fictional status, and an author decision; no generated trace is presented as empirical social fact.
