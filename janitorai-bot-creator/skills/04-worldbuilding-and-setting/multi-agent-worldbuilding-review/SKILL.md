# Multi-agent Worldbuilding Review

Use this skill when a setting needs several domains—culture, institutions, geography, belief, ecology, history, naming, or social conflict—to remain mutually coherent.

## Process

1. Write a short world brief with genre, scale, time frame, viewpoint, constraints, and open questions.
2. Assign each specialist pass a narrow domain and a defined output schema.
3. Merge outputs into a structured world model; retain provenance and unresolved alternatives.
4. Compress the model hierarchically, preserving facts that affect the current locality and scene.
5. Run a contradiction review across chronology, resources, institutions, geography, culture, and character knowledge.
6. Return a contradiction report and proposed repairs for author approval.

## Completion

Stop when every specialist output is either integrated, rejected, or retained as an explicit alternative; every blocking contradiction has a repair or author decision; and the current locality can be rendered without loading the whole world model.
