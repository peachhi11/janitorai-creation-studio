# Initialize Campaign State

Use this skill when starting a new long-running roleplay, converting a story bible into runtime state, or opening a new route.

## Process

1. Define premise, genre contract, time, location, scale, and player-owned areas.
2. Register characters, NPCs, factions, institutions, locations, objects, and current conditions.
3. Record starting relationships, secrets, promises, debts, injuries, goals, and conflicts.
4. Separate world truth, character knowledge, player knowledge, author-only plans, and hypotheses.
5. Define active pressures, opening opportunities, deadlines, and unresolved hooks.
6. Run identity, knowledge, world, relationship, and agency checks before the first scene.

## Completion

Stop when every active participant and pressure has an initialized record, every private fact has access scope, and the opening scene can begin without inventing missing canon silently.
