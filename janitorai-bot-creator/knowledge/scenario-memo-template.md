# Scenario Memo

A scenario memo reinforces important behavioral or contextual information for continued roleplay.

It can be placed in Janitor AI's Advanced Definitions under Character's Note, using the appropriate depth setting.

```text
<scenario memo>

# Memo

## Scenario Notes
- Core personality traits
- Important relationship context
- Established scenario rules
- Distinctive speech behaviors
- Critical continuity information

</scenario memo>
```

A scenario memo should contain concise, actionable facts rather than reproducing the entire character sheet.
