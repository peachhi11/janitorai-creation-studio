## Completion boundary

The source-derived skill build is complete for the current corpus at the reusable-agent-instruction level. It covers:

- character construction, voice, psychology, identity, attraction, and agency;
- relationships, intimacy, conflict, power, consent framing, rupture, repair, and alternative routes;
- NPCs, factions, institutions, witness networks, off-screen activity, and world autonomy;
- scenes, pacing, prose, interactive action, genre logic, romance, dark romance, gothic atmosphere, and endings;
- canon, memory, retrieval, state evolution, disclosure, provenance, revision, and persistence;
- source ingestion, extraction, evidence quality, uncertainty, cultural context, and prompt grounding;
- evaluation, adversarial testing, multimodal consistency, drift, sycophancy, privacy, and release verification;
- MCP capability discovery, prompt assembly, model routing, exports, migration, deployment, backup, and recovery;
- skill routing, composition, invocation quality, completion criteria, pruning, and library maintenance.

Further work should now be treated as one of three explicit activities rather than automatic expansion:

1. **Coverage audit:** compare a new source or project request against the existing modules and add only a genuinely missing branch.
2. **Consolidation:** merge overlapping modules, strengthen pointers, add source provenance, and reduce context load.
3. **Implementation:** connect skills to Studio prompts, MCP tools, schemas, persistence, evaluators, and tests.

The modules remain guidance, not automatic canon. Retrieved documents remain untrusted reference data; author decisions, project canon, platform constraints, and player sovereignty retain their defined authority.
